# 13X1 Hosting — لوحة إدارة مشاريع Python و Node.js

## تشغيل اللوحة على VPS
1. ارفع الملفات إلى مجلد المشروع على الخادم.
2. ثبّت Python 3 و pip.
3. نفّذ:
   ```bash
   pip install -r requirements.txt
   gunicorn --bind 0.0.0.0:21910 app:app --timeout 120
   ```
   أو شغّل `python app.py` للتجربة.
4. اربط الدومين بالـ VPS واضبط Nginx/HTTPS أمام التطبيق.

## Runtime و Console
من صفحة المشروع افتح **Console** ثم قسم **Runtime / نسخة التشغيل**:
- اختر Python أو Node.js / npm.
- اختر نسخة Python أو Node.js أو npm من النسخ المثبتة والمتاحة على الـ VPS. اللوحة لا تستطيع اختيار نسخة غير مثبتة؛ ثبّت النسخة أولاً على السيرفر.
- Python يشغّل الملف المحدد مثل `main.py` ويثبت المكتبات من `requirements.txt`.
- Node.js يشغّل ملفاً مثل `index.js` أو يستخدم `npm start` حسب `package.json`، ويثبت المكتبات بأمر `npm install`.
- اضغط **حفظ إعدادات التشغيل** قبل Start. الكونسول يعرض المخرجات والأخطاء من `server.log`.

### تثبيت Node.js و npm على Ubuntu/Debian
إذا ما ظهرتش اختيارات Node.js/npm، ثبتهم على الـ VPS أولاً:
```bash
sudo apt update
sudo apt install -y nodejs npm
node --version
npm --version
```
بعد التثبيت أعد تشغيل لوحة الاستضافة. لإظهار نسخ متعددة، خاص كل نسخة تكون مثبتة كأمر مستقل في PATH (مثلاً `node20` أو `node22`).

Python: ثبّت النسخ المطلوبة على الـ VPS كأوامر مثل `python3.10`, `python3.11` أو `python3.12`؛ اللوحة تعرض النسخ التي تستطيع اكتشافها فقط.

ملاحظة: حافظ على ملفات `users.json` و`remember_tokens.json` عند التحديث إذا أردت الاحتفاظ ببيانات الحسابات. غيّر بيانات المسؤول قبل إتاحة اللوحة للعموم إذا أضفت لاحقاً آلية تغيير كلمة المرور.


## تحديث لوحة Dashboard
- واجهة جديدة مع إحصائيات المشاريع، بحث، وفلترة حسب Python/Node.js.
- صفحة كل مشروع فيها Console، حالة التشغيل، الموارد، وإدارة الملفات.
- إعدادات Runtime تعرض فقط نسخ Python وNode.js/npm المثبتة فعلياً.
- تثبيت مكتبات Python داخل `.venv` خاص بكل مشروع لتجنب تثبيتها عالمياً على السيرفر.
- تثبيت npm داخل مجلد المشروع عبر `npm install`.
- واجهة API `/api/runtimes` تعرض النسخ المتاحة للمستخدم المسجل.

## تشغيل آمن مبدئياً
استعمل Nginx مع HTTPS، بدّل كلمة سر الأدمن الافتراضية، وخلي اللوحة خلف جدار ناري. مشاريع المستخدمين تشغّل كعمليات نظام؛ للإنتاج العام يفضّل تشغيل كل مشروع بمستخدم Linux أو حاوية منفصلة وحدود CPU/RAM.

## تثبيت تلقائي على Ubuntu/Debian VPS
بعد فك الضغط والدخول لمجلد الملفات:
```bash
sudo bash install_ubuntu.sh
sudo systemctl status 13x1-hosting
sudo journalctl -u 13x1-hosting -f
```
ملف `nginx-13x1-example.conf` مثال لإعداد Nginx للدومين `13x1-team.cc.cd`. راجع DNS وافتح منافذ 80/443، ثم فعّل HTTPS بـ Certbot قبل استعمال اللوحة من الإنترنت.
